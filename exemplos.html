EXEMPLO 01

Estrutura básica de uma página

HTML

Toda página HTML começa com uma estrutura básica. Ela define informações do documento, título e conteúdo que será exibido.

HTML 
<!DOCTYPE html>

<html lang="pt-BR">

<head>
    <title>Meu Site</title>
</head>

<body>

    <h1>Olá, mundo!</h1>

    <p>
        Meu primeiro site.
    </p>

</body>

</html>
Resultado

Olá, mundo!

Meu primeiro site.

Títulos e parágrafos

HTML

EXEMPLO 03

Alterando cores com CSS

CSS

O CSS permite modificar cores, fontes, espaçamentos e diversos outros aspectos visuais dos elementos HTML.

HTML + CSS 
<h1 class="titulo">
    Olá, DevGuia!
</h1>

<style>

.titulo {
    color: #38bdf8;
    background: #0f172a;
    padding: 20px;
}

</style>
Resultado

Olá, DevGuia!

EXEMPLO 04

Criando um layout com Flexbox

CSS

O Flexbox facilita o alinhamento e a distribuição de elementos dentro de um container.

CSS 
.container {

    display: flex;

    justify-content: center;

    align-items: center;

    gap: 15px;

}

EXEMPLO 05

Criando cards com Grid

CSS

O CSS Grid permite organizar elementos em linhas e colunas, sendo muito útil para criar galerias e dashboards.

CSS 
.cards {

    display: grid;

    grid-template-columns:
        repeat(3, 1fr);

    gap: 20px;

}
