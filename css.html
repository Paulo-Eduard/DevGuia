PRIMEIROS PASSOS

O que é CSS?

🎨

CSS significa Cascading Style Sheets, ou Folhas de Estilo em Cascata.

Ele é utilizado para definir a aparência dos elementos HTML, controlando cores, fontes, tamanhos, espaçamentos, posições e layouts. 

h1 {
    color: #38bdf8;
    font-size: 32px;
}
EXPLORAR

Conceitos CSS

01 Seletores

Seletores CSS

Os seletores indicam quais elementos HTML receberão determinado estilo.

CSS 
p {
    color: white;
}

.titulo {
    font-size: 32px;
}

    background: black;
}

02 Cores

Cores

O CSS permite definir cores para textos, fundos, bordas e diversos outros elementos.

CSS

    background-color: #0f172a;

03 Texto

Tipografia

Propriedades de texto permitem controlar fonte, tamanho, peso, alinhamento e espaçamento.

CSS 
.titulo {
    font-family: Arial, sans-serif;
    font-size: 32px;
    font-weight: 700;
    text-align: center;
    line-height: 1.2;
}

Texto estilizado

Esse é um exemplo de tipografia utilizando CSS.

04 Box Model

Box Model

Todo elemento HTML pode ser entendido como uma caixa formada por conteúdo, padding, border e margin.

CSS 
.card {
    width: 300px;
    padding: 20px;
    border: 2px solid;
    margin: 20px;
}

05 Layout

Flexbox

Flexbox é utilizado principalmente para organizar elementos em uma dimensão, horizontal ou vertical.

CSS 
.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 20px;
}

06 Layout

CSS Grid

Grid é ideal para criar layouts em duas dimensões, trabalhando simultaneamente com linhas e colunas.

CSS 
.container {
    display: grid;
    grid-template-columns:
        repeat(3, 1fr);
    gap: 20px;
}

08 Responsividade

Media Queries

Media Queries permitem adaptar o layout para diferentes tamanhos de tela.

CSS 
@media (max-width: 768px) {

    .container {
        grid-template-columns: 1fr;
    }

}

09 Organização

Variáveis CSS

Variáveis permitem armazenar valores reutilizáveis, facilitando a manutenção do projeto.

CSS 
:root {
    --cor-principal: #38bdf8;
    --fundo: #0f172a;
    --texto: #f8fafc;
}

button {
    background: var(--cor-principal);
}
--cor-principal #38bdf8
10 Efeitos

Transições

Transições criam mudanças suaves quando uma propriedade CSS é alterada.

CSS 
.button {
    transition: 0.3s;
}

.button:hover {
    transform: scale(1.05);
}
DICAS

Boas práticas CSS

Alguns hábitos ajudam a manter seu código organizado.

01

Use classes

Prefira classes para estilos reutilizáveis em vez de depender excessivamente de IDs.

02

Organize seu CSS

Mantenha propriedades relacionadas próximas e utilize uma estrutura consistente.

03

Evite repetição

Utilize variáveis CSS e classes reutilizáveis para reduzir código duplicado.

04

Pense responsivamente

Seu layout deve funcionar em diferentes tamanhos de tela.
